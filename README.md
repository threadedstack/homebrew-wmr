# homebrew-wmr

Homebrew tap for wmr.

```sh
brew install threadedstack/wmr/wmr               # the wmr command
brew install --cask threadedstack/wmr/wmr-app    # the desktop app
```

The full name taps `threadedstack/wmr` and installs in one step; on Homebrew 7 and later it also trusts the formula it names, so no `brew trust` is needed. `brew upgrade` keeps both current.
